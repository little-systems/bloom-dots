# Upstream Bloom v3.10.2 port — design

**Date:** 2026-11-14 · **Owner request:** "pull changes from bloom and compare its latest app with ours … I want … what's new in bloom that bloom-dots must be updated", then "write the plan for all seven".

## Why

Bloom for Linux is 1:1 with Windows Bloom (spec 2026-10-25 §10: upstream changes are ported deliberately, release by release). bloom-dots was last measured against Bloom `b5fb962` (2026-10-24). Upstream `little-systems/bloom` main is now `cd04ac9` (v3.10.2 + 2). This port brings the seven user-visible upstream changes since then into bloom-dots, exactly as upstream draws and behaves.

## Baseline

- From: Bloom `b5fb962` (`tools/bloom-audit/README.md`).
- To: Bloom `cd04ac9`. After this port, `tools/bloom-audit/README.md` and this spec name `cd04ac9` as the last ported commit.

## The seven changes

Each item names the upstream commits that are the reference. Exact values come from upstream `src/App.css`, `src/App.tsx`, `src/components/*` at `cd04ac9`.

1. **Edge Shine** (`5012c6f`, `9780280`, `8430e65`, `cd04ac9`). A reflective contour along the dock's and the notch's free edges, through the flares into the screen edge; the collapsed dock pill is outlined all round. New setting `bloom-edge-shine-enabled` (default `true`), Appearance → **Edge shine**, desc "Soft reflections around the dock and notch. Turn off if animations feel less smooth." The OSD does not get it.
   - Contour: upstream `edgeSurfaceContour(width, height, radii, edge, flares)` (pill plus 13 px flares; the closed back-rounded path for a bottom surface without flares).
   - Paint: clipped to the contour, a vertical gradient (stop 0 `line`, 0.45 `side-light`, 1 `highlight`; flipped for the bottom edge so the highlight is on the free edge), stroked 4 px at alpha 0.16, then 2 px at alpha 1. With flares, a horizontal `destination-in` fade: transparent at 0 and at the width, opaque from 13 px in.
   - Colours: `line` = mix(surface solid, theme text, 18 %); `highlight` = mix(line, white, 14 %); `side-light` = mix(line, white, 5 %). The rim sits inside the surface layer, so it takes the surface opacity.
   - It follows the surface through every size and radius animation (`8430e65`, `cd04ac9`).
2. **Calendar browsing** (`6131caf`). Month heading button ("November 2026", 12 px 600) opens a month list and a year field (100–9999, 49 px, 11 px 600) with a ✓ Done button; Escape or leaving closes it. Hover/focus shows a 46×24 pill with ‹ › (22 px round buttons, 13 px chevrons, 120 ms fade). "Today" (9 px, 0.65 opacity, 34 px) shows only away from the current month. Wheel changes month (Shift: year; ignore |delta| < 5; one change per 300 ms); PageUp/PageDown (Shift: year), Home = today. Day names "Sun"…"Sat"; day cells 28 px tall; panel height `112 + rows × 30` for the month shown. "Today" highlight refreshes each minute. The month shown persists while the shell runs (upstream keeps it in App state).
3. **Monday-first calendar** (`875c916`). Setting `bloom-calendar-monday-first` (default `false`), Notch → **Monday-first Calendar**, desc "Start each week on Monday instead of Sunday", shown only while Calendar & Timer is on, right after it. Day order, leading blanks and panel height follow it.
4. **Command Center** (`6131caf`). The slider icons become 22×22 buttons (radius 5, hover and "pressed" background = text at 12 %): Volume mutes / restores the last non-zero level; Brightness goes to 0 / restores the last non-zero level. Icons by level — volume: 0 `volume-x`, < 0.33 `volume`, < 0.67 `volume-1`, else `volume-2`; brightness: < 34 `sun-dim`, < 67 `sun-medium`, else `sun` (12 px, 0.7 opacity). Command Center, Wi-Fi and Bluetooth panels 375 px wide (Devices stays 350). Toggle tiles fully rounded (radius = height / 2). Slider label column 86 px.
5. **Dock: Show Background Apps** (`#376`). Setting `bloom-dock-show-background-apps` (default `true`), Dock → **Show Background Apps**, desc "Keep apps in the dock when they close to the system tray", after Show App Previews. Off: unpinned tray-only apps leave the dock and pinned apps lose the grey background dot; tray actions in the app menu stay.
6. **Timer editing** (`8a8d6a9`). Valid input: 1–5 digits or `m:ss`; seconds must be < 60; 1 s … 180 min. Escape cancels without committing. Enter or Play with an invalid entry keeps the editor open. Status while editing: "Type to set duration". Clock: digit 23×52 (compact 18×44), no gap between digits, colon padding 1 px.
7. **Connected devices kept between visits** (`2fbe394`). Reopening the Devices panel shows the last known devices at once, with no empty frame.

## Approaches

- **Port each change into the existing QML** (chosen): the same surfaces, tokens and tests bloom-dots already has; values copied from upstream.
- Re-audit everything against a fresh Playwright recording first: catches unlisted drift but costs a full audit; the seven items were found by reading the diff, so not needed now. The live check at the end compares the result side by side with the upstream UI in `tools/bloom-audit`.
- Edge Shine via `Shape` strokes instead of `Canvas`: Shape cannot clip a stroke to its own fill or do a `destination-in` fade without extra layers; Canvas' Context2D has `path` (SVG data), `clip`, gradients and composite modes, so the upstream drawing ports line for line. Canvas repaints only when the geometry key changes, as upstream.

## Non-goals

Upstream items that do not apply to Linux: dock menus after the Windows Start menu (`51e24e2`), Settings created on demand (`50bb8ef`), Office ZIP preview hardening (`476845d`), CI/triage, the sponsor link.

## Constraints

- 1:1 parity is literal: exact sizes, fonts, colours and motion.
- Perf budget Intel UHD 620: Edge Shine must not add measurable idle CPU; repaint only on geometry, radius or palette change.
- Settings: new keys in `shell/services/settings.js`; regenerate `docs/SETTINGS.md` and `shell/settings/search-index.js`.
- Icons: add `volume`, `volume-1`, `volume-x`, `sun-dim` to `tools/gen-icons.mjs`; regenerate `shell/common/icons.js`.
- Tests never touch the live session. Full suite runs in CI.
