# Upstream Bloom v3.10.2 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the seven user-visible upstream Bloom changes from `b5fb962` to `cd04ac9` into bloom-dots, 1:1.

**Architecture:** Each change lands in the QML surface that already mirrors the upstream component: `common/EdgeSurface.qml` (shine), `modules/notch/CalendarView.qml` + `calendar.js` (calendar, timer), `modules/notch/CommandCenterView.qml` (sliders), `modules/dock/dock.js` (background apps). New settings go through `services/settings.js` and the existing Settings tabs. Pure logic lives in `.js` files with QtTest unit tests; views get offscreen QtTest view tests.

**Tech Stack:** Quickshell 0.3.2, Qt 6.12 Quick / QtTest / Context2D Canvas, lucide-static icons.

**Spec:** `docs/specs/2026-11-14-upstream-3.10.2-port-design.md`

## Global Constraints

- Branch `feat/upstream-3.10.2` off `main`; conventional commits ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, committed as `git -c user.name="Dhanush Santosh" -c user.email=dhanushsantoshs05@gmail.com commit`.
- Reference is Bloom `cd04ac9` (`~/Projects/bloom`, `git show origin/main:<path>`). Values copied exactly; "1:1 parity is literal".
- Single QML test: `QT_QPA_PLATFORM=offscreen /usr/lib/qt6/bin/qmltestrunner -input tests/qml/<file>.qml`. Full suite runs only in CI.
- After any settings change: `node tools/gen-settings-doc.mjs && node tools/gen-settings-index.mjs`; after icons: `node tools/gen-icons.mjs`. `--check` variants must pass before each commit that touches them.
- Theme colours come from the existing theme object (`theme.text`, `theme.bgExpanded`, `theme.border`, `theme.groupBg`); no new hard-coded colours except upstream's literal `white`.
- New files added after the live shell starts need `systemctl --user restart bloom-shell.service` for live checks; ask the owner before restarting.

## Review Focus

1. Edge Shine during motion: dock expand/collapse, notch panel open/close and radius springs must keep the rim on the surface edge every frame, with no stale bitmap and no repaint while geometry is still.
2. Edge Shine at fractional `bloom-scale` (1.15 on the owner's machine): the 1 px line must stay crisp, with no gaps where the flare meets the pill.
3. Calendar navigation while the panel animates its height: changing month 5 → 6 rows → 4 rows resizes the notch without clipping the last row.
4. Timer editor with the notch losing keyboard focus (pointer leaves): it commits as before, while Escape discards.
5. Background apps off while a pinned app has only a tray icon: the dock icon stays, the dot goes, the tray entries stay in its menu.

Tests for each are in the owning task.
